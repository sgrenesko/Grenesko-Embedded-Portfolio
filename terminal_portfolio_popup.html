ROC CLIMBER

/projects/roc-climber
A custom arcade installation built around a Raspberry Pi 5. The project involved preparing the operating environment, creating deployment scripts, configuring the application to launch reliably, and integrating the software with a physical arcade cabinet. The goal was to turn a standalone game into a dependable public installation. Rather than requiring a keyboard or Linux knowledge at the installation site, the system was configured to boot directly into the experience and recover cleanly after power cycles. This project combined software deployment, Linux configuration, hardware integration, troubleshooting, and real-world testing in a public environment.
STACK: Python / Bash / Raspberry Pi 5 / Linux
STATUS: DEPLOYED

COMPUTER VISION RESEARCH

/projects/computer-vision
A computer-vision and force-probe toolkit developed to improve consistency in prosthetic socket alignment and model preparation. The system combined camera marker tracking, Python processing, and force-point measurements with 3D scan data. The workflow was designed to reduce manual interpretation and make experimental measurements easier to visualize. Marker tracking and scripted processing were used to overlay force-point information onto 3D models, while the surrounding workflow was documented and tested for repeatability. The resulting system achieved approximately 90% accuracy in water-displacement fit testing and provided a more structured approach to prototype evaluation.
STACK: Python / OpenCV / 3D Scanning / Electronics
STATUS: RESEARCH / PROTOTYPE

MSYNTH_PAINT

/projects/msynth_paint
A personal project to demonstrate the usage of data storage and manipulation techniques in embedded systems using a fun and creative medium. The application is a simple draw pad of 64 x 64 pixels where a user can draw an image and then the program will synthesize the image into tones of frequencies varying depending on pixel color and position. The pixel data is bit encoded from 3 separate values to one packed 24 bit integer. This allows the frequency that is played to be based on all three values (R, G, B) rather than a composite, which would lose information. There is currently only one executable which is OS based, so varies in functionality depending on the computer used, but a second branching component is being made that will run on a Raspberry Pi and be a standalone portable device.
STACK: C/C++ / Arduino / Data Structures / PCB Design / I2C
STATUS: ONGOING
